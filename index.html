알람 앱 지원

앱 소개

심플하고 사용하기 쉬운 알람 앱입니다. 일일 알람과 일반 알람을 통해 당신의 하루를 효율적으로 관리하세요.

주요 기능

일일 알람

  • 하루에 한 번 울리는 특별한 알람
  • 오늘 하루를 위한 단일 알람 설정
  • 간편한 설정으로 빠른 알람 지정

일반 알람

  • 최대 5개까지 알람 설정 가능
  • 요일별 반복 설정
  • 다양한 알람음 선택
  • 테마를 통한 알람 배경 커스터마이징

사용 방법

  1. 일일 알람 설정
    • 메인 화면에서 '일일 알람' 선택
    • 원하는 시간 설정
    • 저장하여 완료
  2. 일반 알람 설정
    • 메인 화면에서 '일반 알람' 선택
    • 제목, 시간, 요일 선택
    • 원하는 테마와 알람음 설정
    • 반복 여부 선택
    • 저장하여 완료
